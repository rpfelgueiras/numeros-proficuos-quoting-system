# Orçamentos Numeros Proficuos

Three design proposals for a client-side quote builder. No database, no login: everything runs in the browser and quotes are saved to PDF through the print dialog.

- `opcao-a-cartao.html`: the A4 page is the editor, styled after the business card
- `opcao-b-obra.html`: form plus live preview, laid out like a construction drawing
- `opcao-c-local.html`: four-step flow for use on a phone

Open `index.html` to compare them. Add `#exemplo` to any option's URL to load a sample quote.
